# Fase 1 — Beginner: 1.10 There is / There are

Modul ini membahas struktur "there is" dan "there are" untuk menyatakan keberadaan sesuatu. Topik ini menjadi penutup Fase 1 sekaligus merangkum konsep to be, singular/plural noun, dan pembentukan kalimat negatif serta tanya yang telah dipelajari sepanjang fase ini.

## 1. Pendahuluan

### 1.1 Konteks

Modul ini menggunakan pola to be dari 1.4 dan konsep singular/plural yang sudah tersirat sejak 1.7 This/That/These/Those. Struktur there is/there are akan diperdalam lebih lanjut di Fase 2 melalui konsep countable dan uncountable noun.

### 1.2 Tujuan Pembelajaran

Setelah modul ini, pembelajar mampu:

1. Membedakan penggunaan "there is" untuk tunggal dan "there are" untuk jamak.
2. Membentuk kalimat positif, negatif, dan tanya dengan there is/there are.
3. Menggunakan there is/there are untuk mendeskripsikan tempat dan keberadaan benda.
4. Membedakan penggunaan there is/there are dengan it is/they are.

## 2. Konsep Dasar

"There is" dan "there are" digunakan untuk menyatakan bahwa sesuatu ada di suatu tempat, biasanya saat memperkenalkan informasi baru yang belum disebutkan sebelumnya.

| Bentuk | Digunakan untuk |
|--------|--------------------|
| There is | noun tunggal |
| There are | noun jamak |

## 3. There Is (Tunggal)

Pola: **There is + a/an + singular noun**

Contoh kalimat:

1. There is a book on the table.
2. There is a cat in the garden.
3. There is an apple in the basket.
4. There is a problem with the printer.
5. There is a good restaurant near my house.

## 4. There Are (Jamak)

Pola: **There are + plural noun**

Contoh kalimat:

1. There are five books on the table.
2. There are many students in the classroom.
3. There are two cats in the garden.
4. There are some apples in the basket.
5. There are a lot of people at the concert.

## 5. Kalimat Negatif

Pola: **There is/are + not + noun**

| Positif | Negatif | Contracted |
|---------|---------|---------------|
| There is | There is not | There isn't |
| There are | There are not | There aren't |

Contoh kalimat:

1. There isn't any milk in the fridge.
2. There is not a single chair left.
3. There aren't any students in the room.
4. There are not enough seats for everyone.
5. There isn't a bank near here.

## 6. Kalimat Tanya

Pola: **Is/Are there + noun?**

Contoh kalimat:

1. Is there a hospital nearby?
2. Are there any questions?
3. Is there a problem?
4. Are there enough chairs for everyone?
5. Is there a bus stop around here?

Jawaban singkat:

1. Is there a bank near here? — Yes, there is. / No, there isn't.
2. Are there any seats left? — Yes, there are. / No, there aren't.

## 7. Kata Bantu Kuantitas yang Sering Menyertai

| Kata | Digunakan dengan | Contoh |
|------|-------------------|--------|
| a/an | there is | There is a chair. |
| some | there are (kalimat positif) | There are some books. |
| any | there are/is (kalimat negatif dan tanya) | There aren't any books. / Are there any books? |
| a lot of / many | there are | There are a lot of people here. |
| much | there is (uncountable) | There isn't much time left. |

Contoh kalimat:

1. There are some flowers in the vase.
2. There isn't any sugar left.
3. Are there any messages for me?
4. There is much traffic today.
5. There are many opportunities in this city.

## 8. There Is/Are vs It Is/They Are

Perbedaan penting yang sering membingungkan: "there is/are" dipakai untuk memperkenalkan keberadaan sesuatu untuk pertama kali, sedangkan "it is/they are" dipakai untuk merujuk kembali pada benda yang sudah disebutkan.

| Kalimat Pertama (memperkenalkan) | Kalimat Lanjutan (merujuk kembali) |
|---------------------------------------|------------------------------------------|
| There is a cat in the garden. | It is very cute. |
| There are two books on the shelf. | They are mine. |
| There is a restaurant nearby. | It is quite expensive. |

## 9. Perbandingan dengan Bahasa Indonesia

| Aspek | Bahasa Indonesia | Bahasa Inggris |
|-------|-------------------|-----------------|
| Menyatakan keberadaan | "ada" (tanpa membedakan jumlah) | there is (tunggal) / there are (jamak) |
| Struktur kalimat | Fleksibel, "ada" bisa di awal atau tengah | Struktur tetap: there + to be + noun |
| Subjek gramatikal | Tidak diperlukan subjek formal | "There" berfungsi sebagai subjek gramatikal (dummy subject) |

Kata "there" dalam struktur ini bukan berarti "di sana" secara harfiah, melainkan berfungsi sebagai subjek gramatikal kosong (dummy subject) yang wajib ada dalam kalimat bahasa Inggris, berbeda dengan bahasa Indonesia yang bisa langsung memakai kata "ada" tanpa subjek tambahan.

## 10. Kesalahan Umum

| Kesalahan | Contoh Salah | Koreksi |
|-----------|---------------|---------|
| Salah pilih is/are berdasarkan jumlah noun | "There is many books." | "There are many books." |
| Menghilangkan "there" | "Is a problem." | "There is a problem." |
| Menerjemahkan "there" sebagai "di sana" | Bingung karena mengira harus menunjuk lokasi jauh | "There" di sini adalah dummy subject, bukan penunjuk lokasi |
| Memakai "there is/are" untuk merujuk kembali pada benda yang sudah disebut | "There is a cat. There is very cute." | "There is a cat. It is very cute." |
| Salah pakai some/any | "There are some problems?" (dalam kalimat tanya) | "Are there any problems?" |

## 11. Ringkasan Modul

There is dan there are digunakan untuk menyatakan keberadaan sesuatu, dengan there is untuk noun tunggal dan there are untuk noun jamak. Kata "there" berfungsi sebagai dummy subject, bukan penunjuk lokasi. Struktur ini umumnya dipakai untuk memperkenalkan informasi baru, sedangkan rujukan berikutnya menggunakan it is atau they are. Ketepatan memilih is/are berdasarkan jumlah noun, serta penggunaan some/any yang sesuai konteks kalimat, menjadi poin utama yang perlu dikuasai.

## 12. Catatan Lanjutan: Penutup Fase 1

Modul ini menutup Fase 1 — Beginner. Sepanjang fase ini, pembelajar telah menguasai alfabet dan pelafalan, angka serta waktu, personal pronouns, to be, kosakata dasar, sapaan dan perkenalan, demonstrative, articles, pola kalimat dasar, dan struktur there is/are. Seluruh materi ini menjadi fondasi struktural untuk Fase 2 — Elementary, yang akan memperkenalkan sistem tenses secara sistematis, dimulai dari Simple Present Tense, yang akan langsung memanfaatkan pola subject-verb agreement yang telah disinggung pada modul 1.9.
