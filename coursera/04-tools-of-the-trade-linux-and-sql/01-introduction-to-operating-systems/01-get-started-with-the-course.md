## 1. Posisi Course 4 dalam Program Sertifikat

### 1.1 Tujuan Course 4

Course 4 berjudul **Tools of the Trade: Linux and SQL**, kursus keempat dari sembilan kursus dalam **Google Cybersecurity Certificate**. Fokusnya adalah membangun dasar computing yang mendukung kerja seorang security analyst, mencakup tiga pilar utama:

- Memahami cara kerja **operating system**.
- Berkomunikasi dengan **Linux operating system** melalui command.
- Melakukan **query database** menggunakan **SQL (Structured Query Language)**.

### 1.2 Urutan 9 Kursus Program

Program sertifikat disusun berurutan, setiap kursus membangun dari kursus sebelumnya:

3. **Connect and Protect: Networks and Network Security** — kerentanan level jaringan dan cara mengamankannya.

5. **Assets, Threats, and Vulnerabilities** — kontrol keamanan dan pola pikir threat actor.
6. **Sound the Alarm: Detection and Response** — siklus incident response dan tools deteksi/respons.
7. **Automate Cybersecurity Tasks with Python** — otomasi tugas cybersecurity dengan Python.
8. **Put It to Work: Prepare for Cybersecurity Jobs** — klasifikasi insiden, eskalasi, komunikasi stakeholder, pengenalan AI dalam cybersecurity.
9. **Accelerate Your Job Search with AI** — strategi pencarian kerja dan pemanfaatan AI (Gemini, NotebookLM) untuk persiapan karier.

## 2. Struktur Modul Course 4

Course 4 dipecah menjadi empat modul berurutan, masing-masing membangun skill dari modul sebelumnya.

### 2.1 Modul 1 — Introduction to Operating Systems

Membahas hubungan antara **operating system**, **hardware**, dan **software**, serta fungsi utama sebuah operating system. Mengenalkan sistem operasi yang umum dipakai saat ini dan dua cara interaksi dengan operating system: **Graphical User Interface (GUI)** dan **Command-Line Interface (CLI)**.

### 2.2 Modul 2 — The Linux Operating System

Pengenalan sistem operasi **Linux** dan penggunaannya dalam konteks cybersecurity. Mencakup arsitektur Linux, macam-macam **distribusi (distro) Linux**, serta pengenalan **Linux shell** sebagai media komunikasi antara user dan operating system.

### 2.3 Modul 3 — Linux Commands in the Bash Shell

Praktik command Linux melalui **Bash shell**, mencakup navigasi dan pengelolaan file system, serta proses **authorization** dan **authentication** user. Modul ini juga mengajarkan cara mencari bantuan (help) untuk command yang belum dikenal.

### 2.4 Modul 4 — Databases and SQL

Praktik menggunakan **SQL** untuk berkomunikasi dengan database: melakukan query, memfilter hasil query, dan menggabungkan (**join**) beberapa tabel dalam satu query.

## 4. Syarat Kelulusan dan Sertifikasi

Untuk mendapatkan **Google Cybersecurity Certificate**, dua syarat harus dipenuhi:

1. Membayar **course certificate fee**, atau mengajukan dan lolos **Coursera scholarship**.
2. Lulus seluruh **graded quiz** di kedelapan kursus (bukan sembilan — course terakhir soal job search tidak masuk hitungan graded) dengan skor minimal **80%** pada setiap quiz. Setiap graded quiz berkontribusi pada nilai kumulatif kursus tersebut.

Program bersifat **self-paced**: tidak ada penalti keterlambatan assignment, deadline personal bisa diperpanjang lewat **Switch Sessions** (di menu Overview) atau direset lewat **Reset my deadlines** jika deadline sebelumnya sudah terlewat.

## Glossary — Istilah Kunci

- **Google Cybersecurity Certificate** — program sertifikat sembilan kursus dari Google yang menjadi payung Course 4 ini.
- **Operating System (OS)** — perangkat lunak yang menjembatani hardware dan aplikasi; topik inti Modul 1.
- **GUI (Graphical User Interface)** — cara interaksi dengan OS lewat elemen visual.
- **CLI (Command-Line Interface)** — cara interaksi dengan OS lewat command berbasis teks.
- **Linux** — sistem operasi open-source yang jadi fokus Modul 2 dan 3, umum dipakai dalam cybersecurity.
- **Distro (distribution)** — varian/versi dari sistem operasi Linux.
- **Shell** — program yang menerjemahkan command user menjadi instruksi untuk OS.
- **Bash** — jenis shell spesifik yang dipakai untuk menjalankan Linux command (fokus Modul 3).
- **SQL (Structured Query Language)** — bahasa untuk melakukan query dan manipulasi data di database (fokus Modul 4).
- **Join** — operasi SQL untuk menggabungkan data dari beberapa tabel dalam satu query.
- **Graded quiz** — quiz penentu kelulusan kursus, minimal skor 80%.
- **Practice quiz** — quiz latihan pemahaman, tidak memengaruhi kelulusan.
- **Exemplar** — contoh jawaban/hasil kerja lengkap sebagai referensi validasi.
- **Career identity** — nilai unik dan positioning diri seseorang di dunia kerja.
